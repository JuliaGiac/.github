# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- The visual identity moved to
  [JuliaGiac/site-kit](https://github.com/JuliaGiac/site-kit) (`brand/`),
  with the other parts the web sites share. The profile takes the mark from
  there.

### Added

- Organisation profile (`profile/README.md`) presenting the layers of the
  project, from the upstream Giac/Xcas sources to the Julia packages.
- Visual identity in `brand/`: a G whose crossbar is the overline of a
  square root sign, with the three Julia dots above its opening. Mark for
  light and dark backgrounds, avatar, favicons, touch icon and social
  preview, all generated by `brand/make_brand.jl` (Luxor.jl); palette and
  usage in `brand/README.md`. `just brand` regenerates them.
