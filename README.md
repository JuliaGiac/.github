# JuliaGiac/.github

Organisation-wide files for [JuliaGiac](https://github.com/JuliaGiac).
`profile/README.md` is the text shown on the organisation's GitHub page.
The organisation's web site is <https://juliagiac.github.io/>
([source](https://github.com/JuliaGiac/juliagiac.github.io)).

`brand/` holds the visual identity: the mark, avatar, favicons and social
preview, all generated by `brand/make_brand.jl` (Luxor.jl). See
[`brand/README.md`](brand/README.md); regenerate with `just brand`.
